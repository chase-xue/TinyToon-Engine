## ✨ 核心特性

- 🎨 **纯正手绘卡通动画视觉**：
  - 高清透明精灵（Sprite）图集，告别边缘残影与杂边。
  - 4 帧经典美式奔跑动画循环、待机自然起伏呼吸、急停刹车（Skid）抓地、贴地滑铲扬尘、胜利大拇指等全套动作。
- 👥 **四位标志性主角随时瞬切**：
  - 🐰 **巴斯特兔 (Buster Bunny)**：高跳飞跃、贴地高速滑铲（钻过低矮单格木拱梁与岩石暗道）、空中碰墙蹬墙反冲跳。
  - 🦆 **普拉基鸭 (Plucky Duck)**：空中连续扇翅扑腾升空（最多 4 次）、长空无重力展翅滑翔，轻松掠过深渊大峡谷。
  - 🌪️ **迪兹恶魔 (Dizzy Devil)**：化身狂暴暴风紫龙卷，方向摇杆自由转向狂冲，瞬间粉碎沿途裂纹巨石，秒杀沿途一切小怪。
  - 🐱 **小猫福宝 (Furrball Cat)**：空中利爪牢固紧扣墙壁/高立木攀爬，上下自如游走，反弹蹬跃，地面利爪飞扑突进。
- 📱 **王者荣耀经典手机触控系统**：
  - **左手虚拟移动轮盘 / 摇杆**：智能触控跟随、12px 灵敏死区防误触、松手平滑弹性回中。
  - **右手扇形技能按键群**：右下主跳跃大圆键 (`🦘 跳跃`)、琥珀金专属神技键 (`⚡ 技能`，随英雄动态变换图标与名称)、翡翠绿贴地滑铲键 (`🛹 滑铲`)。
  - **现代通透毛玻璃质感**：半透明 HUD（`opacity: 0.45`），按键下方的地貌、萝卜与敌人 100% 清晰可见。
  - **多点触控与防误触**：禁用 iOS/Android 双击缩放与回弹，支持真机物理触感震动反馈。
- 🎮 **原生手柄 (HTML5 Gamepad API) 即插即用**：
  - 完美适配 Xbox / PlayStation / Nintendo Switch / 常见蓝牙手柄。
  - 左摇杆/十字键走位（消除 0.25 轴漂移），A 键跳跃，X 键释放神技，RT 键滑铲，LB/RB 快速轮换英雄。
- 🔊 **纯算法 Web Audio 声效系统**：
  - 无需下载庞大音频文件，毫秒级合成跳跃、踩踏、破风滑铲、急停摩擦、狂暴龙卷风与童年复古关卡 BGM。
- 🗺️ **完整关卡生态与通关挑战**：
  - 80 列丰富地貌：教学跳跃区、木梁矮拱桥、阶梯岩石丘陵、深渊大峡谷、空中气球踏板、旗帜通关传送门。
  - 经典收藏品与怪物生态：33 颗金灿胡萝卜、巡逻呆呆鼠、狂暴小野牛、高空俯冲巡视蜂。
  - 通关结算弹窗与全量积分统计。

## 🎮 操控指南

### 📱 手机触屏（王者荣耀操作）
* **左侧移动轮盘**：轻推控制前进与后退；推向下控制原地下蹲。
* **右侧跳跃按键 (`🦘`)**：单按起跳；普拉基滞空连续扑腾；空中触墙反向蹬墙。
* **右侧专属特技 (`⚡`)**：释放当前出战英雄的招牌神技（滑铲 / 滑翔 / 暴风龙卷 / 飞檐走壁）。
* **右侧滑铲按键 (`🛹`)**：一键贴地破风前冲穿穴。
* **顶部英雄头像栏**：手指轻点任意头像，0 毫秒即刻秒切变身。

### 🎮 游戏手柄 (Gamepad)
* **左摇杆 / 十字方向键 (D-pad)**：移动走位、下蹲与垂直爬墙
* **A 键 / B 键**：跳跃、滞空升空、蹬墙跳
* **X 键 / Y 键**：释放英雄专属神技
* **RT 扳机键 / LT 键**：一键贴地滑铲
* **LB / RB 肩键**：快速向前/向后轮流切换英雄

### ⌨️ 键盘快捷键 (PC / Mac)
* **移动**：<kbd>A</kbd> / <kbd>D</kbd> 或方向键 <kbd>←</kbd> / <kbd>→</kbd>
* **跳跃**：<kbd>W</kbd> / <kbd>空格 Space</kbd> / <kbd>Z</kbd> / <kbd>J</kbd>
* **下蹲**：<kbd>S</kbd> 或方向键 <kbd>↓</kbd>
* **专属特技**：<kbd>X</kbd> / <kbd>K</kbd> / <kbd>E</kbd> / <kbd>Shift</kbd>
* **快速切换英雄**：数字键 <kbd>1</kbd> 巴斯特兔 / <kbd>2</kbd> 普拉基鸭 / <kbd>3</kbd> 迪兹恶魔 / <kbd>4</kbd> 小猫福宝

## 🚀 运行与启动

本项目为纯原生静态前端架构，零编译依赖，开箱即玩！

### 方式 1：直接浏览器打开
直接在浏览器（Chrome / Safari / Edge / Firefox）中双击打开 `index.html` 即可畅玩。

### 方式 2：局域网多人/手机真机测试（推荐）
启动任意静态 HTTP 服务，手机与电脑连接同一 Wi-Fi，输入对应 IP 即可在真机触屏上畅玩：

```bash
# 使用 Node.js 启动内置服务
npx serve .

# 或使用 Python
python3 -m http.server 8080
```
